# 🍇 Помощьник Бригадира

AI-powered система для учета выполненных работ на виноградниках.

## Возможности

✅ **Быстрый ввод данных** - формат: Квартал N, Клетка N: Фамилия - с X по Y, A; ...
✅ **Автоматические расчеты** - количество рядов и кустов
✅ **Проверка пересечений** - контроль корректности диапазонов
✅ **Офлайн режим** - работает без интернета (PWA)
✅ **Накопление данных** - автосохранение в SQLite БД
✅ **Отчеты** - по клеткам и за период

## Установка и запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Запустите сервер

```bash
npm start
```

Сервер запустится на `http://localhost:3000`

### 3. Откройте приложение

Перейдите в браузер на `http://localhost:3000`

## Формат ввода

```
Дата YYYY-MM-DD:
Квартал N, Клетка N: Фамилия - с X по Y, A; Фамилия - с M по N
Квартал N, Клетка N: ...
```

### Пример:
```
2026-05-06:
Квартал 1, Клетка 1: Иванов - с 1 по 3, 5; Петров - с 6 по 8
Квартал 1, Клетка 2: Сидоров - с 1 по 2
```

## Структура проекта

```
помощьник бригадира/
├── server/
│   ├── server.js      # Express сервер
│   └── parser.js      # Парсер данных с валидацией
├── public/
│   ├── index.html     # Главная страница
│   ├── styles.css     # Стили
│   ├── manifest.json  # PWA конфиг
│   ├── service-worker.js  # Офлайн функционал
│   └── js/
│       └── app.js     # Фронтенд приложение
├── inventory.json     # Инвентаризация (кварталы, клетки, ряды, кусты)
├── data.db           # SQLite база данных (создается при первом запуске)
└── package.json      # Зависимости
```

## Кварталы

Список кварталов задаётся в `inventory.json` (поле `name` у каждого квартала).
Файл локальный, в репозиторий не попадает.
