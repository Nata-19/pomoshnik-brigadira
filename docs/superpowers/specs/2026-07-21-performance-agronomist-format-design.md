# «Выполнение» в формате отчёта агроному — дизайн

**Дата:** 2026-07-21  
**Статус:** утверждён, реализован (2026-07-21)  
**Область:** вкладка «Выполнение» + API га (срез «сегодня»). Бот MAX и гостевой отчёт — вне скоупа.

## 1. Зачем

Бригадир копирует из приложения текст в группу MAX «АГРО Отчет». Сейчас на «Выполнении» другой вид плашек. Нужен вид **как в переписке агронома**, с кнопкой копирования.

Гость на чужом квартале **отчёт не отправляет** — в UI только сводка хозяина квартала (в демо — вся сессия; в проде — кварталы бригадира).

## 2. Формат одной плашки / текста для копирования

Без названия предприятия и без сортов (в демке их нет в отчёте). Пишем **квартал, клетки, бригаду**.

```
За ДД.ММ
Кв.1, клет.1–3,5 · Бр.<метка> (10.50га)
Обрезка
Сделано-4.20га
Сегодня-1.10га
Осталось-6.30га
```

Правила строк:

| Строка | Содержание |
|--------|------------|
| 1 | `За ДД.ММ` — дата отчёта (выбор на вкладке, по умолчанию сегодня) |
| 2 | `Кв.N` + клетки, по которым есть учёт по этому виду работ (диапазоны через `formatRange`), + `· Бр.<метка>` + `(<total_ha>га)` — площадь квартала |
| 3 | Вид работ (как в журнале). Поле «тур» не выводим (в данных нет) |
| 4–6 | `Сделано-`, `Сегодня-`, `Осталось-` с числами в га, формат как на скрине (без пробела после «Сделано-», с пробелом после «Сегодня -» — **как на скрине клиента**) |

Числа: 2 знака после запятой, разделитель **запятая** в тексте для копирования (как «128,22га» на скрине); на экране плашки допускается точка — но в буфер обмена всегда запятая.

**Метка бригады (`Бр.<…>`):**
- прод: имя вошедшего бригадира (или номер бригады, если позже появится поле — пока имя);
- демо: `демо` (одна сессия, отдельных бригад нет).

## 3. UI вкладки «Выполнение»

1. Поле даты «Отчёт за» (flatpickr, как на вводе).
2. Кнопка «Обновить» (как сейчас).
3. Фильтры видов работ / кварталов — без изменений по смыслу.
4. Список плашек в формате §2 (не таблица «Сделано / Осталось» одной строкой).
5. На каждой плашке кнопка **«Скопировать»** → текст §2 в буфер, краткий тост «Скопировано».
6. Кнопка **«Скопировать всё»** — все **видимые** (после фильтров) плашки подряд, через пустую строку.

Пустой список — прежний текст «Пока ничего не записано…».

## 4. Данные и API

Расширить `GET /api/report/hectares`:

- query `date=YYYY-MM-DD` (обязателен для «Сегодня»; если не передан — сегодня по серверу UTC+3 или дата клиента — **передаём с клиента явно**).
- В каждой строке ответа дополнительно:
  - `today_ha` — га, учтённые **только за эту дату** (та же формула, что `done_ha`, но только логи с `date = date`);
  - `cells` — список клеток (строки), по которым есть площади/ряды в накопленном `done` для этой группы (для подписи «клет.…»).

Группировка по-прежнему: `(kind, estate, work_type, quarter)`.  
`done_ha` / `total_ha` / `remaining_ha` — как сейчас.  
`today_ha` ≤ `done_ha`; если за дату ничего нет — `0`.

Юнит-тесты агрегатора: кейс с двумя датами → `today_ha` только за выбранную.

## 5. Вне скоупа

- Автоотправка в MAX / бот.
- Гостевой отчёт (люди + ряды) — не делаем.
- «N тур» в тексте.
- Названия хозяйств/сортов в тексте плашки.

## 6. Критерий готовности

- На «Выполнении» плашка читается как сообщение из скрина (квартал, клетки, бригада, три строки га).
- Смена даты меняет «Сегодня» и строку «За …».
- «Скопировать» даёт текст с запятыми в числах, вставляется в MAX без правок.
- Контроль рядов и остальные вкладки не затронуты.
